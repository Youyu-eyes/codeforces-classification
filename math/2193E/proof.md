# 调和级数枚举
## 代码形式
形如
```go
for i := 1; i < MX; i++ {
    for j := i; j < MX; j += i {
        // 具体操作
    }
}
```
这样的代码称为调和级数枚举，本质上是对每个数的因子进行枚举，时间复杂度为严格的 $\mathcal{O}(U\log U)$，其中 $U$ 为值域。

## 复杂度证明
展开看具体的枚举次数。
- 当 $i = 1$ 时，内层从 $1$ 开始，枚举 $\dfrac{U}{1}$ 次
- 当 $i = 2$ 时，内层从 $2$ 开始，枚举 $\dfrac{U}{2}$ 次
- ...
- 当 $i = U$ 时，内层从 $U$ 开始，枚举 $\dfrac{U}{U}$ 次

全部的枚举次数进行累加，即为
$$
\frac{U}{1} + \frac{U}{2} + \frac{U}{3} + \dots + \frac{U}{U}
$$
我们提取 $U$ 之后为
$$
U\cdot (1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{U})
$$
括号内部为调和级数部分和，即证明该级数部分和上界为 $\log U$.

## 级数上界
定义一个函数 $f(x) = \dfrac{1}{x}$，则该函数单调递减。

考虑函数上一点 $(k, \dfrac{1}{k})$，假设 $k \in [2, U]$.

在 $[k - 1, k]$ 区间内，总有 $f(x) \ge f(k)$\
即 $\dfrac{1}{x} \ge \dfrac{1}{k}$

因此
$$
\frac{1}{x} \ge \frac{1}{k}
$$
即
$$
\int_{k-1}^{k}\frac{1}{x} \, dx \ge \int_{k-1}^{k}\frac{1}{k} \, dx = \frac{1}{k}
$$
计算 $\dfrac{1}{k}$ 从 $2$ 到 $U$ 的和
$$
\sum_{k=2}^{U}\frac{1}{k} \le \sum_{k=2}^{U}\int_{k-1}^{k}\frac{1}{x}\, dx = \int_{1}^{U}\frac{1}{x}\, dx = \ln U
$$
> $\le$ 右边的等式是对 $[1, 2]$，$[2, 3]$，$[3, 4]$ 等连续区间的定积分，每一项上界与下一项的下界相等，被积函数相同，即为对 $[1, U]$ 的连续积分

不等式两边加上 $1$ 后
$$
1 + \sum_{k=2}^{U}\frac{1}{k} \le 1 + \ln U
$$

左半边为上文所述的调和级数部分和，右半边在大 $O$ 记号下可以忽略常数 $1$，因此我们可以证明，调和级数部分和的上界为 $\mathcal{O}(\log U)$

> 注意调和级数本身是发散的，这里证明的是调和级数部分和，$U$ 在题目中是有上界的。
